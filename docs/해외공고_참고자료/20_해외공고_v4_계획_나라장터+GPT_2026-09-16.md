## 3. 설계

### 3-1. 판별 2단계 (놓침 방지 우선)
1. **규칙 A** — 정규식 `태국|방콕|치앙마이|치앙라이|푸켓|파타야|끄라비|후아힌|코사무이|아유타야|thailand|bangkok|chiang ?mai|phuket|pattaya|thaifex|bitec|qsncc|impact (arena|exhibition|muang)|퀸시리킷|무앙통타니` → **확정, GPT 안 거침** (GPT 장애 시에도 태국 명시 건은 반드시 발송)
2. **GPT** (gpt-4.1-mini, 제목+기관, 60건 배치, 제목 캐시) → `grade` B/X + `type`(용역/모집/채용/안내) + `topic`
   - B: 동남아·동남아시아·아세안·ASEAN·메콩·인도차이나 등 태국 포함 가능성 높은 권역. 국가 목록에 태국이 빠져 있으면 X.
   - X: 국가·권역 미명시 일반 해외사업, 타 지역, 단어 우연 일치, 국내
3. 사용자 원칙 반영: "주체가 태국 관련이면 장소 무관" — 태국 바이어 방한, 태국 인플루언서 초청 등도 A (제목에 태국이 있으므로 규칙으로 잡힘)

### 3-2. 소스 구성
- **신규 `g2b`** — `g2bApi.callSearchApi` 재사용, 위 키워드 10개 × days_back 5 × 100건. `overseas_notices` 에 `source='g2b'` 로 저장 (채용 `notices` 테이블과 분리). 첫 실행 백필: 1년치 A+B 147건 저장(메일 X).
- 기존 8소스: 수협·지식재산보호원·KOTRA 는 무키워드 전체 수집으로 전환, aT·기업마당은 키워드 확장(태국·방콕·동남아·아세안·ASEAN·thailand·bangkok), 문화원·교육원 그대로. 모든 소스 → 3-1 판별.
- 재조사 엑셀(221곳) 반영: **198곳이 "나라장터" 방식 → g2b 채널로 커버.** S 등급 중 미크롤 5곳은 파서 추가 후보 (다음 단계): KOCCA 태국비즈니스센터, 중진공 방콕 GBC/해외민간네트워크, 경기 GBC 방콕(GBSA), KOFICE 입찰공고, SBA 글로벌마케팅.

### 3-3. 요약 (제출기간 D-day · 금액 · 주제)
- g2b: 검색 행에서 마감·금액 즉시. 주제는 GPT `topic`.
- 8소스: 상세 페이지 텍스트 → GPT `{deadline, deadline_kind, amount, topic, summary}`. 금액 null 이면 2단계 첨부 텍스트 추출.
- D-day 는 **발송 시점** 기준 계산. 마감 지난 건 "마감" 표시, 마감 없는 건 "-".

### 3-4. 메일
- 섹션 [A 태국 확정] → [B 동남아·아세안 권역]. 각 행: `D-n` 배지 · 기관 · 제목(링크) · 유형 · 금액 · 주제. **D-day 오름차순.**
- B 등급(동남아·아세안)도 **같은 메일에 전부 포함** (2026-09-16 결정). A 섹션 다음에 B 섹션.

### 3-5. 비용
- 제목 판별: 609건 → 11회 호출 ≈ $0.02. 일일 50~100 제목 → 무시 가능.
- 상세 요약: 건당 ~4k 토큰 ≈ $0.001.
